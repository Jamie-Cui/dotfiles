* dotfiles

Personal Linux and macOS config deployed with [[https://www.gnu.org/software/stow/][GNU Stow]].

** Prequisites

*** macOS

#+begin_src bash
xcode-select --install
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install stow
#+end_src

*** Fedora

#+begin_src bash
sudo dnf install git make stow
#+end_src

*** Deploy

#+begin_src bash
mkdir -p ~/opt
git clone https://github.com/Jamie-Cui/dotfiles.git ~/opt/dotfiles
cd ~/opt/dotfiles
make dry-run
make bootstrap
#+end_src

** Cross-platform apps

Run =make bootstrap= once after installing the apps below.

*** Oh My Zsh

#+begin_src bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
#+end_src

*** Vim (=vim=)

#+begin_src bash
brew install vim                 # macOS
sudo dnf install vim-enhanced    # Fedora
#+end_src

*** Neovim (=nvim=)

#+begin_src bash
brew install neovim              # macOS
sudo dnf install neovim          # Fedora
#+end_src

*** Emacs (=emacs=)

#+begin_src bash
brew install --cask emacs-app    # macOS
sudo dnf install emacs           # Fedora

cp ~/.emacs.d/local.el.example ~/.emacs.d/local.el
cp ~/.emacs.d/early-local.el.example ~/.emacs.d/early-local.el
#+end_src

Requires Emacs 30.1 or newer.  Edit only the copied =local.el= files for
machine-specific settings.

#+end_src
